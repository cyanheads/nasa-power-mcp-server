# 0.1.1 — 2026-10-19

## Added

- **Observations** — hourly, daily and monthly point time series, monthly and annual climatology, tilted solar profiles, native-grid regions, and comparisons across 2–10 labeled locations.
- **Discovery** — parameter search and reference guidance for communities, coverage, missing values, wind corrections and five parameter presets.
- **Analytical datasets** — complete larger results stage in optional DuckDB workspaces for explicit-token describe and bounded read-only SQL; table removal is opt-in.
- **Scientific output** — source units, provenance, omitted parameters, null missing values and period-aware completeness accompany observations on both output surfaces.
- **Distributions** — npm and Docker support native analytics; the portable MCPB supports inline results. Eight tools are enabled by default, with a ninth for table removal.
- **Documentation** — usage, configuration and distribution contracts include DuckDB platform support; `api-canvas` 2.9 and `api-config` 1.27 describe Windows ARM64 support.

## Fixed

- **DuckDB startup** applies fixed canvas defaults through initialization ([#1](https://github.com/cyanheads/nasa-power-mcp-server/issues/1)).
- **Observation requests** omit the invalid application user identifier ([#2](https://github.com/cyanheads/nasa-power-mcp-server/issues/2)).
- **Parameter dictionaries** preserve nullable upstream metadata for monthly and climatology calls ([#3](https://github.com/cyanheads/nasa-power-mcp-server/issues/3)).
- **Table removal** retains provenance access after the producing request ends and returns accurate removal results ([#4](https://github.com/cyanheads/nasa-power-mcp-server/issues/4)).
- **Hourly selections** advertise the 15-code maximum and report effective correction-inclusive counts ([#5](https://github.com/cyanheads/nasa-power-mcp-server/issues/5)).
- **Reference size errors** provide dictionary-specific recovery guidance ([#6](https://github.com/cyanheads/nasa-power-mcp-server/issues/6)).

## Dependencies

- **`@duckdb/node-api`** added at `^1.5.6-r.1` for native analytical workspaces.
