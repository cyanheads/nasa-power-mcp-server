# 0.4.2 — 2026-10-29

## Added

- **`summaryCount` and `summaryDataset`** on `nasa_power_get_timeseries` and `nasa_power_get_climatology` output (both optional): when the envelope without observations overflows the inline budget, `summaries` holds one entry, `summaryCount` the exact total, and `summaryDataset` the complete table, read in `summaryIndex` order (#33).

## Changed

- **Wide point selections** (such as several `*_HR` groups mixed with ordinary codes) were refused with `dataset_limit` under both providers. Under DuckDB the same call is now served with the staged summaries; under `CANVAS_PROVIDER_TYPE=none` the refusal moves to `canvas_required` carrying `rowCount`, `inlineRows` and parameter-group `calls` that each fit inline. `dataset_limit` remains only when the compact envelope still does not fit (#33).
- **`nasa_power_get_region` `canvas_required` tiles** share a bound at the midpoint between adjacent returned cells instead of sitting on cell coordinates, so only the bounds inside `calls` move, and boxes on coarse grids (1° solar parameters) that listed no calls now list a split (#32).
