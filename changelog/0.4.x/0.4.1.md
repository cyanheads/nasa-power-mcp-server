# 0.4.1 — 2026-10-28

## Changed

- **Producer admission** reserves an estimate computed from the request (periods, points or cells, effective columns) instead of the 48/64 MiB worst case, and a call that cannot be admitted waits up to 15 s inside the 55 s deadline, now started at tool entry (#26). The tenant (64 MiB) and process (128 MiB) in-flight ceilings still hold.
- **`producer_capacity_exhausted`** (rate limited, retryable) replaces `canvas_capacity_exhausted` when other data calls hold the in-flight capacity; **`canvas_busy`** (rate limited, retryable) replaces it for a busy canvas or full query pool, with recoveries that say to retry when the other call returns (#26). Canvas-count, table and retained-staging refusals keep `canvas_capacity_exhausted`.
- **`canvas_required`** refusals from the four producing tools carry `rowCount`, `inlineRows` and `calls` in both the recovery text and error `data`: re-sendable per-call request changes that each fit inline (#29).
- **`nasa_power_search_parameters`** omits the unserved codes below before counting and paging, with a `notice` naming any the filter matched (#27).

## Fixed

- **`GDD4_4`, `GDD7_2`, `GDD10`, `GDD13_3`, `GDD15_6`** at monthly and climatology, and **`ALLSKY_SFC_SW_{DIFF,DNI,DWN}_HR_{MAX,MIN}`** at monthly, are rejected before any request with `unsupported_parameter` and a family recovery; POWER answered them with HTTP 500, and regional monthly `GDD*` with all-fill values (#27).
- **Group codes** (`*_HR` at monthly and climatology, `*_HR_MAX`/`*_HR_MIN` at climatology, `SI_TRACKER_AVG`/`MIN`/`MAX`) list their returned members under `expansions` and are no longer reported in `omittedParameters` (#30).
- **A retried call's reservation** no longer keeps the discarded attempt's bytes, so a retry measures the same as a first-try success (#31).
