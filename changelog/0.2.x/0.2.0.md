# 0.2.0 — 2026-10-20

## Changed

- **Canvas lifecycle:** Dropping the last table now retires its canvas; subsequent describe, query, and drop calls with that token return `canvas_not_found`. ([#10](https://github.com/cyanheads/nasa-power-mcp-server/issues/10))
- **DuckDB** is enabled by default for npm and Docker; set `CANVAS_PROVIDER_TYPE=none` to disable staging. The portable MCPB remains inline-only.
- **Normalized request output schemas** share typed fields while preserving every request echo, including per-location provenance. ([#13](https://github.com/cyanheads/nasa-power-mcp-server/issues/13))
- **Output limits** above 100 dictionary entries or 1,000 SQL rows use the effective cap with a notice; explicit parameter codes deduplicate after normalization and date schemas advertise their Gregorian shape. ([#14](https://github.com/cyanheads/nasa-power-mcp-server/issues/14))
- **`agroclimatology`** adds `T2M_MAX` and `T2M_MIN` outside hourly resolution; reference entries show exact expansions and retain source-period semantics. ([#16](https://github.com/cyanheads/nasa-power-mcp-server/issues/16))

## Fixed

- **Location comparisons** stage complete observations, bucket summaries and per-location summaries together, returning bounded previews and ordered SQL handles with exact counts. Failed registrations roll back the entire batch. ([#9](https://github.com/cyanheads/nasa-power-mcp-server/issues/9))
- **Wind corrections** use all 17 canonical NASA surface aliases, preserving vegetation underscores and documented airport-ice aliases. ([#8](https://github.com/cyanheads/nasa-power-mcp-server/issues/8))
- **SQL diagnostics** retain bounded caller-correctable identifiers and conversion values with recovery guidance, excluding engine paths, stacks and native causes. Operational errors retain safe classifications. ([#12](https://github.com/cyanheads/nasa-power-mcp-server/issues/12))
- **Upstream 429 errors** report `retryable: true` to callers while preserving fail-fast handling, cooldown and `Retry-After`. ([#15](https://github.com/cyanheads/nasa-power-mcp-server/issues/15))
- **Documentation** aligns tool usage, native distribution defaults and canvas persistence guidance.
