# 0.3.0 — 2026-10-24

## Added

- **Canvas sizing** honors validated memory, tenant capacity and lifetime overrides; `NASA_POWER_MAX_CANVASES_PER_PROCESS` controls process capacity with the existing default of eight ([#19](https://github.com/cyanheads/nasa-power-mcp-server/issues/19)).
- **Regional summary staging** returns complete observation and summary tables with `summaryDataset`, exact `summaryCount`, ordered `summaryIndex` retrieval and linked provenance; registration failures roll back the complete new batch ([#24](https://github.com/cyanheads/nasa-power-mcp-server/issues/24)).
- **Point climatology** accepts optional `canvas_id` for workspace reuse and stages oversized profiles completely with bounded previews ([#23](https://github.com/cyanheads/nasa-power-mcp-server/issues/23)).

## Changed

- Regional climatology no longer accepts startYear or endYear; omit both even when they match the source period (#20). Use point climatology for custom year windows.
- **SQL columns named `current_schema`** now require table qualification: use `c.current_schema` rather than `current_schema` when selecting that CTE column.
- **Development tooling** follows the adopted framework guidance and audit classification; Bun runtime and Docker images move from 1.4.3 to 1.4.4.
- **Hosted access** is documented at `https://nasa-power.caseyjhand.com/mcp` and advertised in registry metadata.

## Fixed

- **Climate-zone codes** `T_ZONES` and `TM_ZONES` retain numeric values with categorical metadata and no arithmetic summaries or numeric comparison sorting; shared source units remain present independently of numeric comparability ([#21](https://github.com/cyanheads/nasa-power-mcp-server/issues/21)).
- **Tilted-solar aliases** `SI_TILTED_AVG`, `SI_TILTED_MIN` and `SI_TILTED_MAX` report only their returned members in `expansions` and are omitted only when no member returns ([#22](https://github.com/cyanheads/nasa-power-mcp-server/issues/22)).
- **Environment initialization** loads `.env` before server-specific parsing; framework error text and link rendering preserve literal source values on both response surfaces.
